    Quick guide
    
  
    
    
    1. Write
    Type or paste your message on the left. The first line is the subject, a blank line starts a new paragraph. Use the toolbar to add a type, scope or emoji.
    
    
    2. Pick your terminal
    Choose Bash / Zsh, PowerShell or CMD. The command is quoted for that shell, so $, backticks, !, % and backslashes stay as typed.
    
    
    3. Pick an output mode
    Stream pipes the message into git and is safe for any text. Compact is one line with one -m per paragraph. File downloads commit-msg.txt and works in every shell.
    
    
    4. Copy and run
    Open a terminal in your repository, paste, and press Enter. Nothing runs from the website. Each copied command is saved to History.
    
    
    Smart sections
    Lines under Owner actions: become a checklist outside the commit. Lines under Removed files: can become a git rm command.
    
    
    Private and offline
    Everything runs in your browser. No account, no tracking, no network calls. Install it as an app and it works offline.
